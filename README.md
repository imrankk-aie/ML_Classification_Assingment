## Introduction

This project implements a **binary classification model** to predict whether a NYC taxi trip is a short trip or a long trip based on features like passenger count, pickup/dropoff coordinates, and vendor information.

The complete pipeline covers data collection, preprocessing, exploratory analysis, model training, and result visualization — all steps as required in the assignment.

### How to download the dataset

1. Go to https://www.kaggle.com/competitions/nyc-taxi-trip-duration/data
2. Sign in to Kaggle (free account)
3. Click **Download All**
4. Extract the zip — use `train.csv` (the main file, ~2 GB)
5. Place `train.csv` in the same folder as the notebook
